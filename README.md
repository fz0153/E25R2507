# Pixel Survival 项目说明

这是由五人团队共同开发的浏览器像素生存游戏，核心入口为 [index.html](./index.html)。
团队共同设计并制作了一款融合“探索 + 生存 + 生产 + 扩展”的 2.5D 游戏，并将内容创作能力（地图、道具、流程、技能、机器、Mod）整合进同一套游戏框架中。

## 1. 项目定位

- 类型：浏览器 2.5D 像素生存游戏
- 开发方式：五人团队协作开发
- 运行方式：直接用浏览器打开 HTML 文件即可运行，无需构建工具链
- 技术栈：HTML + CSS + JavaScript + Canvas
- 核心价值：团队协作完成可玩的游戏本体，并提供内容编辑与模组扩展能力
- 设计特征：既有生存系统，又有自动保存/读档能力，还具备 Game Studio 与 Mod API，可扩展内容与玩法

## 2. 团队开发说明

本项目由五名成员共同开发。团队围绕游戏设计、功能实现、内容制作、模块整合和测试完善等工作进行协作；各成员的实际姓名与具体负责内容应以团队分工和个人工作报告为准，本说明不预设个人分工。

项目采用按功能拆分代码的方式，便于成员分别开发和检查相关模块。完成各部分后，需要共同确认脚本加载顺序、共享游戏状态、存档兼容以及游戏内的整体运行效果。

## 3. 核心玩法概览

玩家在世界中进行生存与探索，游戏循环通常包括：

1. 收集资源：木材、石头、食物、矿石、水源等
2. 制造与升级：制作工具、建筑、机器、装饰与设施
3. 管理状态：监控饥饿、水分、体力与健康
4. 探索世界：地面、洞穴、河流、生物群落、敌人与资源分布
5. 发展文明：建立村落、与村民交易、解锁技能与提升战斗能力
6. 扩展创作：利用 Game Studio 或 Mod API 增加新内容

## 4. 主要功能模块

### 4.1 世界探索与地图系统

- 包含地面、洞穴、河流、森林、山地、沙漠、雪地等不同 biome
- 支持生成地图和编辑地图
- 支持日夜循环、季节、天气变化和环境风险
- 地下洞穴与地表环境连接，增加探索深度

### 4.2 生存系统

- 饥饿值、水分值、体力值等核心状态
- 昼夜变化、季节与天气影响游戏环境
- 需要通过采集、烹饪、饮水、休息等方式维持生存
- 资源管理和环境压力构成游戏的挑战来源

### 4.3 采集与制造

- 采集木材、石头、植物、食物与资源材料
- 通过合成系统制造工具、台阶、建筑、药品、装置等
- 支持多种 item、block、recipe 的组合和扩展
- 机器与工业流程可进一步提升生产效率

### 4.4 农业与动物系统

- 支持作物种植与生长
- 作物成长受光照、水分、季节和天气影响
- 包含动物养殖、喂养、繁殖等内容
- 通过调度和资源投入进行小型生态经营

### 4.5 村庄与交易

- 设有村庄与 NPC / 村民系统
- 可通过交易进行物品买卖
- 形成“资源采集—生产—贸易”的循环

### 4.6 成长与技能系统

- 杀敌、打怪、探索等行为获取经验值
- 通过技能树解锁新能力
- 提供装备、战斗、移动、耐力等不同增益
- 技能可通过 Game Studio 编辑与扩展

### 4.7 存档与数据管理

- 自动保存功能
- 支持多份手动存档
- 支持导入/导出存档内容
- 保存数据与地图配置可持续保留并复用

### 4.8 自定义内容与扩展系统

- Game Studio 提供可视化编辑界面
- 支持地图、物品、方块、机器、食物、技能等内容设计
- Mod API 允许在不重写游戏主逻辑的前提下注册新内容
- 适合学习“游戏内容扩展”与“模组开发”思路

### 5.1 JS 模块职责概览

从脚本加载顺序来看，游戏逻辑分为以下几个关键模块：

- core.js：核心基础逻辑和全局状态
- world.js：世界生成与地图管理
- player.js：玩家状态、行动、属性与控制
- update.js：更新循环与状态刷新
- render.js：渲染与绘制
- hud.js：界面显示与状态栏
- crafting.js：合成系统
- skills.js：技能树与能力系统
- village.js：村庄与交易
- growth.js：成长与经验系统
- save.js：存档管理
- mod-api.js：Mod 接口暴露
- studio.js：Game Studio 内容编辑器
- startup.js：启动入口

此外还包含 input.js、panels.js、guns.js、tooltip.js、item-icons.js、theme.js 等辅助模块，用于输入、面板、道具图标、主题、提示和互动支持。

## 6. 项目特点

### 6.1 适合浏览器运行

项目没有复杂构建流程，直接打开入口文件即可启动。适合课堂作业、原型开发、演示展示和快速迭代。

### 6.2 高度可扩展

不仅是一个可玩的游戏，本项目还提供：

- 角色外观编辑
- 物品/方块/机器定制
- 地图编辑
- 技能节点配置
- 音效与视觉资源导入
- 模组注册与内容包导出

这使其具备“游戏本体 + 内容创作平台”的双重定位。

### 6.3 团队开发成果与学习价值

本项目是五人团队协作完成的游戏作品，也体现了多人共同开发前端游戏时的模块划分、功能整合与测试协作。项目内容可用于：

- 学习 HTML5 Canvas 游戏开发
- 练习 JavaScript 模块化设计
- 探索生存游戏系统架构
- 研究 mod / content pipeline
- 进行原型开发和玩法实验

## 7. 运行方式

1. 打开项目根目录中的 [index.html](./index.html)
2. 在浏览器中直接运行，页面将加载游戏主逻辑与界面
3. 如需调试和自定义内容，可打开开发者控制台
4. 如需体验 Mod，可以将 [Pixel_Survival_Plus_Mod_API_Example.js](./Pixel_Survival_Plus_Mod_API_Example.js) 中的示例代码粘贴到控制台执行

## 8. 注意事项

- 本项目没有完整的脚本构建流程，直接以浏览器方式运行即可
- 游戏脚本按顺序加载，若添加或调整 JS 文件，需同步检查 [index.html](./index.html) 中的脚本顺序
- Mod API 不是安全沙箱，解析和执行脚本时必须只加载可信内容
- 自定义内容和 Mod 可能会影响游戏状态和存档兼容性，需注意版本更新时的兼容性

Pixel Survival 是五人团队共同开发的像素生存游戏，包含：

- 可运行的游戏本体
